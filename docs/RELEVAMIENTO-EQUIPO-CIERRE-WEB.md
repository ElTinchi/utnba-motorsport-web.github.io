# Información a recolectar para cerrar la web de UTN BA Motorsport

Preparado el 15/09/2026. Complementa la [auditoría FIUBA vs. UTN](AUDITORIA-FIUBA-VS-UTNBA-2026-09-15.md).

**Cómo usarlo:** nombrar un coordinador, asignar cada bloque y recibir una única devolución consolidada. No hace falta que el equipo redacte textos publicitarios: alcanza con datos, archivos y aprobación. La redacción web se hace después.

Cada respuesta debe incluir **responsable, fecha de actualización, fuente y permiso de publicación**. Si algo todavía no existe, escribir «no definido», «en desarrollo» o «no publicable»; eso permite cerrar la web sin inventar información.

## 10. Acuerdo de cierre

**La web se considera terminada cuando representa honestamente el estado actual del equipo, permite las acciones importantes y tiene un responsable de mantenimiento.** No necesita que el auto esté terminado ni que todos los datos de ingeniería sean definitivos.

Para cada faltante elegir una salida: dato aprobado, descripción de estado actual o exclusión deliberada de esa información. Evitar dejar promesas de «próximamente» sin responsable y fecha de revisión.
